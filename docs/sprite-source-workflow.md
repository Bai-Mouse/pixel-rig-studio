# PNG 复用、裁剪与项目副本

## 已导入 PNG

在 Image library 中点击「+」或导入框。
「New PNG…」从磁盘导入；「Imported PNG」选择项目中已有的原图。
选择已有原图后可以预览、自动识别部件或手动画框，导入新切片不会覆盖旧切片，且共用同一个源图关联。
「Replace this sheet…」替换整张源图，刷新全部关联切片，保留 sprite ID、节点绑定及动画帧中的贴图选择。
替换图不足以容纳已有裁剪范围时会报错，不会进行部分替换。

## 只替换单个 sprite

选中一个 sprite，在 inspector 的「Source PNG crop」里选择「PNG for this sprite」，
或点「Choose new PNG for this sprite…」。调整裁剪范围后，点击「Apply source & crop」才应用。
只改变选中 sprite 的源图，其他 sprite 不受影响；节点和动画帧继续使用原来的 sprite ID。
尺寸不同时会将裁剪框限制到新源图内，请预览确认后再应用。

「Replace entire source sheet…」则是另一种操作：替换这个 sprite 当前所属的整张源图并更新所有关联切片。

## 贴图锚点（Sprite anchor）

节点属性面板和图片面板都有 **Sprite anchor**：X/Y 是贴图内的像素坐标，表示贴图上哪一个像素要对齐到节点原点。
没有设置锚点的贴图继续使用节点 pivot，所以旧项目行为不变；一个节点挂多张贴图时，可以让每张图各有对齐点。

- **Center**：把锚点设到当前贴图中心；**Use node pivot**：清除自定义锚点，回到节点 pivot
- 画布 **Pivot 工具（P）**：调整锚点时**不会移动已经画出来的像素**。贴图有自定义锚点时改该锚点并补偿节点位置；
  没有自定义锚点时改节点 pivot（保持像素不动，只改旋转中心）
- 用 Pivot 工具时画布会显示所有可见节点的原点十字，当前节点用橙色高亮，方便确认锚点位置
- 锚点编辑可以用 Ctrl+Z 撤销

裁剪范围时锚点会按源图坐标重映射，继续对准同一个源像素；如果锚点落在新裁剪范围外，会被夹到边缘。
对还没有锚点的贴图执行裁剪时，会以当前选中节点的 pivot 生成锚点，避免贴图在节点上跳位。
裁剪编辑器里的琥珀色圆环标出当前锚点对应的源图像素。

画布、导出 GIF/APNG/PNG 序列和精灵表都使用同一个锚点。

## Character template 首次设置

首页点 **Character template** 会先打开设置对话框，确认后再进入编辑器：

- **Parts**：列出模板的全部部件（节点名 + 第几张图），点击选中
- **Sheet & part region**：显示当前整张贴图，可直接换 PNG（Import PNG…），拖拽或输入数值调整选中部件的裁剪框，
  然后 **Apply region to part**。换整张图时会沿用原有切片矩形并自动夹进新图范围，再逐个部件细调
- **Pose preview**：选中部件后在预览画布里拖动，即可先微调节点的初始位置；滚轮以鼠标位置为中心缩放
  （50%–800%，`+` / `−` / **Fit** 按钮同样可用），中键或空白处拖动平移；**Reset pose** 恢复内置位置，
  **Reset template** 恢复内置贴图与位置
- **Create project** 进入编辑器；Cancel 放弃

## 原图缩放与锚点

- 原图预览支持 +/−、滚轮缩放、Fit、1:1。
- 中键拖动平移，也可以用滚动条查看放大后的源图。
- 裁剪框四角和四边共八个拖拽点可调整大小，框内部可拖动位置。
- 九点 Coordinate anchor 控制 X/Y 数值的参考点，以及用 W/H 修改尺寸时固定的点。
  切换锚点本身不会移动裁剪范围，也不改变角色节点的 Pivot。
- 应用裁剪、替换源图或导入切片后，可用 Ctrl+Z 撤销，Ctrl+Y / Ctrl+Shift+Z 重做。
  编辑历史仅保留在当前会话中。

## 制作项目副本

顶部「Project → Make project copy」会复制当前项目的贴图、节点、帧和设置，并在名称后加上「- Copy」。
副本不继承原项目的保存路径，首次 Save 会重新选择位置；本次会话内也会阻止把副本写回原项目路径。
选好副本的新路径后，后续 Save 会继续保存到这个新路径。原项目文件不会自动被改写。

工具栏分为两行：上排为项目操作、模式、保存、导出和 Codex；下排为节点工具、Transform、View 与像素渲染设置。

验证：`node scripts/test-asset-workflow.mjs`。
