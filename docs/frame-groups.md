# 帧分组：新建、加入已有分组、把帧移出分组

时间轴上的分组只是"帧的标签"：同一个 `group.id` 的帧会共用名称和颜色，播放时可以从任意成员帧开始只循环这一组。

## 新建分组或加入已有分组

1. 点时间轴工具栏的 **Group frames**，进入选帧状态；
2. 在时间轴上点选要归组的帧（可多选，再点一次取消）；
3. 点 **Create group (N)** 打开分组对话框；
4. 在 **Add to** 下拉里选择：

| 选项 | 结果 |
| --- | --- |
| New group | 下面的名称、颜色可用，按填的值新建一个分组 |
| 已有分组（如 `Run (4 frames)`） | 选中的帧直接加入这个分组；名称和颜色沿用原分组，不被覆盖 |

按钮文字会跟着变成 **Create group** 或 **Add to group**，对话框标题会显示 `2 selected frames → Run` 这样的目标提示。选中的帧如果原本属于别的分组，会被移动到目标分组（旧分组最后一名成员离开时就自然消失）。

## 把帧移出分组

点击工具栏当前帧所属分组的 **Edit “分组名”** 按钮：

- **Remove selected**：只把当前选中的帧移出这个分组，其他成员照旧保留分组。选中一帧再点，就是"把这一帧去掉 group"；
- **Remove all**：把这个分组的全部帧都移出（原来的 Ungroup frames），分组随之消失；
- 名称、颜色修改仍然走 **Save group**。

对话框副标题会显示 `4 grouped frames · 1 selected`，提示按钮会作用于几帧；没有选中任何组内帧时 **Remove selected** 是灰色不可点的。

## 撤销

新建分组、加入已有分组、移出选中帧、移出全部、改名改色，每一下都是**一笔撤销记录**，`Ctrl+Z` 能整笔回退（详见 [timeline-undo.md](timeline-undo.md)）。
