# 动画导入：替换、差值叠加、插入与覆盖

时间轴工具栏 `Import animation` 左边的下拉决定导入的 `.animation.json` 怎么落到当前时间轴上。
所有模式的起始位置都是**当前选中的帧**（下拉里会显示成 `frame N`）。

## 四种模式

| 模式 | 行为 | FPS / loop |
| --- | --- | --- |
| Replace timeline | 整条时间轴替换成文件里的帧，跳到第 1 帧 | 采用文件里的值 |
| Apply deltas from frame N | 差值模式：把文件里每一帧相对**前一帧**的变化量，从第 N 帧开始一帧一帧叠加到已有姿势上 | 保留项目当前值 |
| Insert at frame N | 从第 N 帧插入，原有帧整体后移 | 保留项目当前值 |
| Overwrite from frame N | 从第 N 帧覆盖，文件更长时往后追加 | 保留项目当前值 |

## 差值模式怎么算

导入文件的第 1 帧只作为基准，因此**第 N 帧保持原样**，后续每一帧都是在上一帧结果上继续叠加：

- `position`：当前 +（本帧 − 上帧）
- `rotation`：当前 +（本帧 − 上帧）的角度增量；不强制取最短弧，跨 ±180° 的长旋转会原样保留
- `scale`：当前 ×（本帧 ÷ 上帧）的倍率；上帧某轴为 0 时退化为加法
- `visible`、`imageIndex`、`sortingOrder`：只有本帧与上帧不同时才跟着变
  - `visible` 直接采用动画里的值
  - `imageIndex` 按差值累加，并夹在该节点的贴图数量范围内
  - `sortingOrder` 按差值累加

第 k 帧的结果基于第 k−1 帧的结果，所以是「从当前姿势出发复现这段运动」，而不是把文件里的绝对姿势搬过来。

## 帧结构与保留规则

- 写入已有帧时保留帧 ID、帧分组和逐帧绘制层（`canvasData`）；差值模式只改姿势
- 文件比剩余时间轴长时，超出部分追加为新帧
- 起始帧越界会被夹到时间轴末尾；差值模式在末尾没有基准帧时导入会失败并保持时间轴不变
- 帧选择和播放状态会重置，但撤销栈不会：一次导入就是一笔可撤销操作，Ctrl+Z 会回到导入前的时间轴（替换模式下连 FPS 和循环设置一起恢复）
- 文件里没有任何节点能与当前角色匹配时，所有模式都会拒绝导入
