# 双骨骼 IK 与锁脚

在 **Nodes** 模式下，开启工具栏的 **IK**（快捷键 **I**）。在节点树选一个手腕、脚踝或空末端节点。它的父节点和祖父节点就是工具要旋转的两节关节，画布会显示实际使用的链：

`大腿 → 小腿 → 脚踝 / 空末端`

两段都要有长度。如果小腿下面没有末端，可以添加空子节点，再用 Move 把它移到希望固定的位置（例如脚底接地点）。IK 使用的是末端节点的枢轴，而不是贴图边缘。

展开 **IK bindings** 可以从列表选末端，检查两节关节，并把链命名保存，例如 `左脚`。旧项目不需要预先绑定。已保存的绑定不会因节点换父级而悄悄改用另一套关节；层级改变后，面板会提示 **Rebind**。

- **拖绿色控制柄的中心**：调整姿势，肩肘或髋膝自动跟随。到达极限后不会拉长骨骼。拖外圈只旋转末端，不移动末端枢轴。可用 **Reverse bend** 翻转膝盖或肘的弯曲方向。
- **拖紫色菱形**：把它拖过上关节到末端的连线，让膝盖或肘弯向另一侧。末端的位置和朝向不变，已锁脚时也可用。若两节完全伸直，没有空间改变弯曲侧，先把末端略往回移。
- **Lock foot**：把当前帧的脚固定在橙色标记。多选帧时，用当前帧的位置给全部选中帧设置同一个锁点；有任一帧够不到时，不会部分锁定。
- **Move (W)**：选躯干或骨架根节点，拖红色 X 或绿色 Y 箭头可以沿画布单轴移动，拖夹角里的小方块可以同时移动两轴。腿会保持已锁定脚的位置。Inspector 中编辑祖先节点的 Position 也会保持锁点。若腿长不够，移动会受到限制。要摆动这只脚，回到 IK，选中它并点 **Unlock foot**。

这是逐帧编辑工具：结果直接写入选中的帧，不会生成插值。IK 拖动、锁脚、反向弯曲和带锁移动都可以用 **Ctrl+Z** 撤销。项目文件保存锁点；导出的动画数据只包含求解后的帧姿势。锁脚约束用于位置编辑，不会在播放或任意 FK 旋转后自动重算。
