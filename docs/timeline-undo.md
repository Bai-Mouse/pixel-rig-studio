# 时间轴操作的撤销与重做

以前只有姿势编辑（画布拖动、Inspector 数值）能撤销，插入帧、删除帧、导入动画这类"改时间轴结构"的操作是不可撤销的。现在它们和姿势编辑共用同一个撤销栈，按操作发生的顺序回退。

快捷键：`Ctrl+Z` 撤销，`Ctrl+Y` 或 `Ctrl+Shift+Z` 重做（macOS 用 `Cmd`）。节点模式和绘制模式都能用。

## 可以撤销的帧操作

| 操作 | 撤销后恢复的内容 |
| --- | --- |
| Insert / Duplicate frame | 帧列表、当前帧、帧选择 |
| Delete（单帧或多选） | 被删掉的帧、各帧的绘制层 `canvasData`、帧分组、当前帧、帧选择 |
| 拖动帧排序 | 原来的顺序、原来的当前帧 |
| In-between（补间插入） | 插入的过渡帧整体消失 |
| Group frames / Edit group / Ungroup | 分组名称、颜色、成员 |
| 加入已有分组（Add to group） | 被移入目标的帧回到原来的归属（或无分组） |
| Remove selected / Remove all（移出分组） | 被移出的帧重新回到该分组 |
| Action template（Walk / Idle） | 模板插入的 6 帧整体移除 |
| Import animation（Replace / Deltas / Insert / Overwrite） | 导入前的整条时间轴；Replace 模式连 FPS 和循环设置一起恢复 |

一次操作只产生一笔撤销记录，一次 Ctrl+Z 整笔回退，不会退到"插入了一半"的中间状态。

## 和姿势编辑共用一个栈

时间轴操作和姿势编辑按真实发生顺序排列，例如：先拖动节点，再删一帧，此时 Ctrl+Z 先恢复被删的帧，再按一次才撤销节点拖动。

重做栈在新操作之后会清空（和常见编辑器一致）：撤销一次删除后如果又插了一帧，就不能再"重做"那次删除了。

## 绘制模式的笔迹撤销

绘制模式（`Frame drawing`）里的画笔笔迹有自己的逐帧撤销记录。在这个模式下按 Ctrl+Z 时：

1. 如果撤销栈顶是时间轴操作（导入、删帧、分组、插入……），先撤销时间轴操作；
2. 否则才撤销当前帧的笔迹。

这样"删帧 → Ctrl+Z"不会只把笔迹撤掉却留下删帧的结果。

## 内存与上限

帧列表是不可变数据，撤销记录只保存帧数组的引用，不复制像素或姿势数据，因此一整笔操作几乎不额外占内存。撤销栈最多保留最近 **80** 笔（姿势编辑、AI 编辑、贴图编辑共用这个上限），超出后丢弃最旧的一笔。
