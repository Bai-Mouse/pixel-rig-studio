# 多选帧编辑节点

时间轴用 Ctrl/Cmd 点选或 Shift 范围选择帧，画布上方会显示正在编辑的帧数量。

- 画布移动：各选中帧增加相同的本地坐标位移。
- 画布旋转：各选中帧增加相同的旋转角度。
  鼠标手势先转换到父节点的本地坐标，自身水平/垂直翻转不会反转操作方向；镜像、非等比缩放或产生剪切的父级也会正确换算。越过 ±180° 可以继续旋转，不会跳角。
- 画布缩放：各选中帧按相同的 X/Y 比例缩放，保留各自的镜像方向和姿势差异。
- 工具栏及 Inspector 的 Flip H / Flip V：分别翻转每个选中帧原有的缩放方向。
- Reset：将所有选中帧的变换恢复为节点默认变换，保留各帧的可见性、贴图选择和排序。
- Inspector 输入数值：只将所改字段设置为同一个值；未编辑的字段保持各帧原值。
- 帧贴图选择、Sorting Order 和帧可见性也联动选中帧。添加到节点的贴图会在选中帧上启用。
- 删除也联动选中帧：选中帧里包含当前帧时，Delete 会一次删除全部选中帧；不包含时只删除当前帧（与上面的多选规则一致）。删除后当前帧指向被删位置之后仍在的帧，至少保留一帧，不允许把时间轴删空。

未选中的帧和其他节点不会被这些帧属性操作改动。一次画布拖拽、翻转、重置或 Inspector 字段编辑只生成一笔撤销记录，可用 Ctrl+Z 整笔撤销，Ctrl+Y / Ctrl+Shift+Z 重做。

节点层级、名称、贴图列表、锁定、层级树总可见性和 Pivot 属于共享节点属性，仍然作用于整个项目，不改成帧独立属性。

测试：`node scripts/test-multi-frame-transform.mjs`。

镜像旋转回归测试：`node scripts/test-rotation-direction.mjs`。此测试曾复现旧公式的 +30° 鼠标运动变成 −30° 节点旋转：旧公式多乘了节点自身水平翻转的负号，并且错误地把世界坐标鼠标角度直接用作本地旋转角度。
